Project Methodology

This analytics project employs an end-to-end meteorological data processing pipeline:

  • Data Ingestion: Historical daily records (2022–2025) are retrieved via the official Open-Meteo Archive REST API utilizing ECMWF ERA5 reanalysis modeling at 0.25° spatial resolution.
  • Real-Time Integration: High-resolution 7-day numerical weather predictions and live current observations are retrieved via the Open-Meteo Forecast API.
  • Seasonal Classification: Aligned with official India Meteorological Department (IMD) standards: Winter (Jan–Feb), Summer / Pre-Monsoon (Mar–May), Monsoon (Jun–Sep), and Post-Monsoon (Oct–Dec).
  • Statistical Calculations: Pearson correlation coefficient (r), year-over-year percentage variances, diurnal thermal amplitudes, and threshold-based precipitation metrics (rainy day >= 1.0 mm).

Data Sources & Limitations

Primary Data Sources:

  • Open-Meteo Historical Archive API – ERA5 atmospheric reanalysis archive (ECMWF).
  • Open-Meteo Forecast API – Multi-model ensemble (GFS, DWD ICON, ECMWF).

Dataset Scope & Limitations:

  • Geographic Scope: Exclusively calibrated for five Indian metropolitan centers: Mumbai, Delhi, Bengaluru, Kolkata, and Chennai.
  • Microclimate Variances: Reanalysis grid coordinates represent regional station centroids and may not capture localized urban heat islands or hyper-local orographic cloudbursts.
